# HotspotShield VPN Web Wrapper (Unofficial)

An open-source, lightweight Firefox extension designed to integrate HotspotShield VPN services directly into your browser interface.

## 🌟 Key Features

- **Open Source & Transparent:** Fully open-source codebase. Anyone can inspect, audit, or review the source code directly on GitHub for total peace of mind.
- **Direct & Secure Connection:** Zero data proxying. Your traffic connects directly to official HotspotShield servers—no user data, traffic logs, or personal information pass through any private or developer-owned servers.
- **Seamless Integration:** Conveniently toggle your connection and manage basic VPN controls straight from your Firefox toolbar.

- **Independent Project (Unofficial):** This extension is an independent, open-source creation. It is not affiliated with, endorsed by, or officially linked to HotspotShield, Aura, Pango, or any of their parent companies. All product names, logos, and brands are property of their respective owners.
- **Account Required:** You will need an active HotspotShield account to use this extension.
